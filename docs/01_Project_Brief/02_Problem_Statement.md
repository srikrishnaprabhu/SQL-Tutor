# SQL Tutor — Problem Statement

## 1. Background

Structured Query Language (SQL) is a fundamental skill for working with relational databases and is widely used in software development, data analysis, database administration, and information systems.

Learning SQL requires both conceptual understanding and practical experience. Learners need opportunities to write queries, execute them, understand the results, identify errors, and apply concepts to realistic problems.

---

## 2. Problem

Many SQL learning approaches separate theoretical learning from practical query execution and assessment.

A learner may study a SQL concept from one resource, write queries in another environment, and use a separate platform or manual process to determine whether the solution is correct.

This fragmented approach can make it difficult for learners to:

- Connect SQL theory with practical implementation.
- Practise queries in a controlled environment.
- Receive immediate feedback on submitted solutions.
- Progress from simpler to more challenging SQL problems.
- Track their learning and assessment performance.

There is therefore a need for an integrated environment that combines SQL learning, practical query execution, automated assessment, and progress tracking.

---

## 3. Proposed Problem Solution

SQL Tutor proposes an integrated interactive platform for SQL learning and assessment.

The platform will allow users to:

1. Learn SQL through structured modules and lessons.
2. Study practical SQL examples.
3. Write SQL queries using an interactive editor.
4. Execute queries against controlled practice datasets.
5. Receive automated evaluation of submitted solutions.
6. Complete SQL challenges and assessments.
7. Track learning progress and exercise performance.
8. Practise SQL through interview-style questions.

The platform will use an isolated SQL execution environment to ensure that learner-submitted queries do not directly interact with application data.

---

## 4. Problem Statement

> **SQL learners often have to rely on separate resources for learning concepts, writing and executing queries, practising problems, and assessing their understanding. This separation can make practical learning and progress tracking less effective. SQL Tutor aims to address this problem by providing an integrated interactive platform that combines structured SQL learning, controlled query execution, automated assessment, practical challenges, and learner progress tracking within a single environment.**

---

## 5. Project Motivation

The project is motivated by the need to make SQL learning more practical and interactive.

Rather than focusing only on theoretical explanations, SQL Tutor will encourage learning through a cycle of:

**Learn → Practise → Execute → Evaluate → Improve**

This approach is intended to help learners connect SQL concepts with practical query-writing skills.

---

## 6. Expected Contribution

The project will contribute a working prototype of an integrated SQL learning and assessment environment.

The system will demonstrate how:

- Structured learning content can be combined with practical SQL execution.
- SQL queries can be automatically evaluated against predefined requirements.
- A controlled database environment can support safe SQL practice.
- Learner activity can be recorded to provide progress information.
- Web and mobile interfaces can provide access to a shared learning platform.

---

## 7. Project Boundary

The problem addressed by this project is limited to interactive SQL learning and assessment.

The initial version will not attempt to provide:

- AI-based tutoring.
- AI-generated learning content.
- Full database administration training.
- Multiple database management systems.
- Enterprise database infrastructure.
- Public commercial learning services.

These areas may be considered as future enhancements.
